Controller Attributes Behavior

Attribute Description
HttpPost / HttpPut / HttpDelete Automatically logged in logsRequest table (Admin Area)
HttpGet Not logged unless explicitly marked
[YesGet] Forces HttpGet action to be logged
[NoLogging] Excludes action from logsRequest table
[AdminAuthorize] Restricts access to authorized users only
[IgnoreAction] Excludes action from permission (claims) storage
[ValidateAntiForgeryToken] Protects POST requests against CSRF attacks

Routing Convention

Routing Rule Explanation
[Area("AreaName")] Defines application area (Admin, Member, etc.)
[Route("Area/Controller/Action")] Standardized route mapping for all controllers

Common Exceptions & Handling

Error Handling Behavior
404 NotFound Returned when entity or id is missing

Rule Behavior
