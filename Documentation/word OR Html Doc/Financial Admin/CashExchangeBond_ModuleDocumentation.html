    OTP Workflow – Document 1 (Cash Disbursement Request)
    StepRoleBehavior
    New AddAccountantNotification sent
    First SignAccountantEdit disabled except Manager
    Second SignManagerPrint enabled + Document 2 unlocked
    Edit After SignManagerAccountant signature removed
    Delete RuleAllDisabled after first signature

    OTP Workflow – Document 2 (Exchange Proof)
    StepRoleBehavior
    When Doc2 Opened(Enabled)AccountantNotification sent
    First SignAccountantManager notified
    Second SignManagerPrint enabled + Document 3 unlocked

    OTP Workflow – Document 3 (Acknowledgment Receipt)
    StepRoleBehavior
    When Doc3 Opened(Enabled)AccountantNotification sent
    Final SignAccountantPrint enabled – workflow complete
