    Trainer Management Module Documentation

    TrainerController – Overview

    ASP.NET Core Controller for managing trainers with user integration, department assignment, and comprehensive reporting capabilities.

    Controller Configuration

    Setting Value
    Area Admin
    Authorization AdminAuthorize
    Dependencies ITrainerService
    IUnitOfWork
    IMapper

    Main CRUD Operations

    Index Action

    Aspect Description
    Purpose Main trainer listing with user integration
    Data Structure Join between Trainer and User entities
    Search Arabic/English trainer name, user-based filtering
    Includes Related Courses per trainer
    UI Features Pagination (50/page), AJAX partial views, department context

    AddEdit (GET)

    Feature Details
    Purpose Create or edit trainer form
    User Selection Dropdown excludes users already assigned as trainers
    Department Assignment Department dropdown population
    Mode Auto-detect create vs edit using ID

    AddEdit (POST)

    Aspect Description
    Validation ModelState validation with dropdown state retention
    File Handling PDF validation, max size 5MB
    Redirect Create → Index, Edit → same page

    Delete

    Aspect Description
    Method HTTP POST
    Flow Service deletion then redirect to Index
