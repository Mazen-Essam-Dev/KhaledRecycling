    IDCardExtractedDataVM Properties

    Property Type Description
    lable string? AI-predicted document type (e.g., ID)
    Probability_double double? Classification confidence (0–100)
    ProbabilityString string? Formatted probability percentage
    doneAI_bool bool? AI classification success flag
    doneOCR_bool bool? OCR extraction success flag
    doneValidation_bool bool? Data validation success flag
    textExtracted string? Raw OCR extracted text
    matchIDNumber string? Extracted ID number
    matchFullEnName string? Extracted English name
    matchFullArName string? Extracted Arabic name
    matchBirth string? Extracted date of birth
    matchExpiryDate string? Extracted ID expiry date
    matchGender string? Extracted gender
    matchNationality string? Extracted nationality

    IDClassificationController — Processing Flow

    Step Description
    1 Validate uploaded file
    2 Run AI image classification
    3 Check confidence threshold (≥ 90%)
    4 Convert image to grayscale
    5 Extract all OCR text fields
    6 Populate IDCardExtractedDataVM
    7 Optional data comparison & validation

    CompareService Capabilities

    Method Purpose
    LevenshteinDistance Calculates character edit distance
    SimilarityPercentage Returns similarity percentage (0–100)
