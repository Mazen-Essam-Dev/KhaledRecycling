    Member HomeController Overview

    Item Value
    Namespace FougeraClub.Areas.Member.Controllers
    Controller HomeController
    Area Member
    Base Route Member/Home/[action]

    Controller Responsibilities

    Responsibility Description
    Dashboard Rendering Displays the main member home dashboard
    Courses & Activities Fetches member-related courses and activities
    Localization Handles Arabic / English language switching
    Error Handling Displays custom error pages for HTTP errors

    Injected Dependencies

    Dependency Type Purpose
    _unitOfWork IUnitOfWork Centralized repository access
    _accountService IAccountService Member account and authentication logic
    _activityService IActivityService Retrieves member activities
    _courseService ICourseService Retrieves member courses
    _httpContextAccessor IHttpContextAccessor Session and HTTP context access
    _mapper IMapper Entity → ViewModel mapping

    Controller Attributes

    Attribute Description
    [Area("Member")] Registers controller under Member area
    [Route("Member/[controller]/[action]")] Defines route pattern
    [YesGet] Custom attribute Save this Get(action) to (Logs) as by default Any Get No Save in Logs
    [MemberAuthorize] Restricts access to authenticated members
    [IgnoreAction], [AllowAnonymous] Excludes actions from authorization
    [NoLogging] Excludes actions from Saving in (Logs)

    Main Action — Index (Dashboard)

    Aspect Details
    HTTP Method GET
    Authorization MemberAuthorize
    Return Type View(HomeActivityCourseVM)
    Purpose Displays personalized dashboard for the logged-in member

    Index Action — Processing Steps

    Step Description
    1 Detect current language from session
    2 Check recent login to display success toast
    3 Retrieve member email from session
    4 Load courses and activities for the member
    5 Filter courses by start date (today or later)
    6 Map entities to CourseVM and ActivityVM
    7 Attach subscription data (attendance, rating, acceptance)
    8 Build HomeActivityCourseVM
    9 Return populated View

    ViewData Used
