    Course Module – Member Area Documentation

    CourseController – Overview

    Aspect Description
    Area Member
    Purpose Manages member interactions with courses (listing, subscription, rating, certificates)
    Advanced Features OCR, AI-based ID validation, SignalR notifications

    Controller Attributes

    Attribute Purpose
    [MemberAuthorize] Restricts access to authenticated members
    [Area("Member")] Registers controller in Member area
    [Route("Member/[controller]/[action]")] Defines explicit routing

    Injected Dependencies

    Dependency Responsibility
    IUnitOfWork Database access and transaction management
    IHttpContextAccessor Session and user context access
    ICourseService (Member) Member-side course logic
    ICourseService (Admin) Certificate generation and reporting
    IOCRService ID card OCR text extraction
    IHubContext<NotificationHub> SignalR real-time notifications
    INotificationService Persistent notification handling

    Controller Actions

    Action Purpose Return Type
    IDClassification_Json (POST) AI-based ID image validation and OCR extraction JSON
    Index (GET) Displays available courses with subscription state View
    TestSignalR (GET) Sends test notifications to admin groups JSON
    GetCourse (GET) Returns single course details via AJAX JSON
    Subscribe (GET) Prepares subscription page with document validation View
    Subscribe (POST) Handles course subscription and notifications & Check OCR Validation if Added a new ID Card #Commented#now Redirect
    Rate (POST) Stores member course rating JSON
    PrintCertificate (GET) Generates printable course certificate View

    CourseService – Member Area

    Method Description Return

    AddRateAsync Adds rating to course subscription Task<bool>
    GetAllAsync Returns courses and member subscriptions Tuple
    GetByIdAsync Fetches course by ID Course?

    UpdateAsync Updates existing course Task
    DeleteAsync Deletes a course Task
    Exists Checks course existence bool

    Course Entity

    Property Type Description
    Id int Primary key
    DepartmentId int? Related department
    TrainerId int? Assigned trainer
    TitleAr / TitleEn string? Multilingual course titles
    StartDate / EndDate DateOnly? Course duration
    Location string? Course venue
    AttachmentPath string? Course materials
