    AppDubaiTime Helper

    Overview

    Description
    Static utility class providing Dubai timezone-aware date and time operations for applications requiring consistent time handling in the UAE timezone.

    Core Properties

    Property Type Description Usage
    Now DateTime Current date and time converted to Dubai timezone Real-time Dubai time operations
    Today DateOnly Dubai current date without time portion Date-only business logic
    NowOffset DateTimeOffset Dubai date and time with timezone offset preserved Timezone-aware persistence

    Conversion Methods

    Method Purpose Implementation Details
    ConvertToDubaiDateTime Converts UTC DateTime to Dubai timezone Ensures UTC kind, converts using TimeZoneInfo.ConvertTimeFromUtc, returns Dubai-localized DateTime

    Usage Example

    Example
    var utcTime = new DateTime(2024, 1, 1, 10, 0, 0, DateTimeKind.Utc);
var dubaiTime = AppDubaiTime.ConvertToDubaiDateTime(utcTime);
