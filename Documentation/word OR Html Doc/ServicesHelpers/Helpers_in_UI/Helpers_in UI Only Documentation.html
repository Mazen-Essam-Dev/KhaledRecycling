    PaginatedList

    Overview

    Description
    Generic pagination utility for efficient data handling in web applications with support for search, filtering, and pagination metadata.

    Properties

    PropertyTypeDescription
    ItemsList<T>Paginated items
    PageIndexintCurrent page number
    PageSizeintItems per page
    TotalPagesintTotal pages
    CountintItems on current page
    TotalCountintTotal items across all pages
    SearchTermstring?Search query
    dateFromstring?Start date filter
    dateTostring?End date filter
    HasPreviousPageboolIndicates previous page exists
    HasNextPageboolIndicates next page exists

    Usage Example

    Example
    var query = _context.Users.AsQueryable();
var paginated = PaginatedList<User>.Create(query, pageIndex: 1, pageSize: 10);
