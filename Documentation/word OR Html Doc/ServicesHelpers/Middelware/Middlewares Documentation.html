    NotificationMiddleware Documentation

    File Structure

    Component File
    NotificationMiddleware NotificationMiddleware.cs

    Core Class

    Class Description
    NotificationMiddleware ASP.NET Core middleware that automatically handles toast notifications for CRUD operations by intercepting HTTP responses and storing session-based messages.

    Constructor Dependencies

    Dependency Purpose
    RequestDelegate next Invokes the next middleware in the pipeline

    Methods

    Method Purpose Parameters
    InvokeAsync Processes HTTP requests and sets toast notifications based on controller action results. HttpContext context
    IStringLocalizer for localization

    Operation Detection Logic

    Condition Behavior
    HTTP Method Processes POST requests only
    Area Excludes Identity area requests
    Status Code Triggers notifications on 302 redirects
    Route Analysis Detects CRUD action from route values

    Action-Specific Notifications

    Action Condition Toast Key Toast Type
    AddEdit No ID ToastAdd Success
    AddEdit With ID ToastEdit Success
    Create — ToastAdd Success
    Edit — ToastEdit Success
    Delete — ToastDelete Error
    Other — ToastDone Success

    Error Handling

    Status Code Toast Key Toast Type
    500 ToastFailed Error

    Session Storage

    Session Key Description
    ToastMessage Localized notification text
    ToastType Visual style (success / error)
    ToastKey Unique toast identifier

    Middleware Registration

    // Program.cs
app.UseMiddleware<NotificationMiddleware>();

    Logging Rules

    Rule Behavior
