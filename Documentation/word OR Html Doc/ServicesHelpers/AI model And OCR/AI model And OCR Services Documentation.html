    CompareService

    Overview

    Description
    Service class for string comparison. Implements ICompareService. Provides Levenshtein distance and similarity percentage calculations.

    Methods

    LevenshteinDistance

    SignatureDescription
    public async Task<int> LevenshteinDistance(string s, string t) Calculates the Levenshtein distance between two strings (minimum number of insertions, deletions, or substitutions).

    SimilarityPercentage

    SignatureDescription
    public async Task<double> SimilarityPercentage(string? s, string? t) Returns a percentage (0-100) representing similarity between two strings based on Levenshtein distance. Returns 0 if either string is null.

    OCRService

    Overview

    Description
    Service for extracting text from images using Tesseract OCR and ImageSharp. Supports preprocessing, grayscale conversion, and custom cropping for ID Cards.

    Namespaces Used

    Namespace
    Tesseract
    SixLabors.ImageSharp
    SixLabors.ImageSharp.Processing
    Microsoft.AspNetCore.Http

    Core Methods

    MethodDescription
    ReadAllTextAsync(IFormFile imageFile) Reads all text from uploaded image without cropping.
    ReadCropped_MarginXY_TextAsync(string grayPath, float marginXRatio, float marginYRatio) Crops image using margin percentages, then extracts text.
    ReadCropped_Custom4_TextAsync(string grayPath, float xL, float xR, float yU, float yD, string? lang = null) Crops by custom ratios (Left, Right, Top, Bottom) and applies OCR.
    ReadGrayTextAsync(IFormFile imageFile) Converts uploaded image to grayscale and returns saved path.
