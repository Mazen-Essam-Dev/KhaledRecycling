    OTP & Signature Workflow

    StepBehavior
    1Trainer receives OTP and signs first
    2Edit disabled for Trainer after signing & Delete disabled for any User
    3Notification sent to Activity Monitor
    4Activity Monitor validates OTP and signs
    5Notification sent to Manager
    6Manager validates OTP and signs
    7Edit & delete disabled for all users
    8Project Card and Print enabled

    Controller Actions

    ActionHTTPDescription
    IndexGETList projects with search, date filter, pagination, AJAX support

    CreatePOSTSave project with file uploads and validation

    EditPOSTUpdate project and files
    DeletePOSTDelete project if no signatures exist
    PrintGETPrintable filtered list
    ProjectCardGETDisplay project card
    SendOtpPOSTSend OTP to selected role
    ValidateOtpPOSTValidate OTP and store signature
