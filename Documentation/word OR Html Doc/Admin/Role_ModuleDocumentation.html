    RoleNumber Enum

    Namespace Domain.Enums
    Purpose Defines application-specific numeric identifiers for user roles.

    RoleNumber Enum Users should Signs Assigned Manually from DB

    Name Value Description
    NormalUser 1 Standard user with permissions and is not allowed to sign a signature in this project.
    Manager 2 User with managerial permissions and signature authority.
    ActivitiesSupervisor 3 User responsible for supervising activities and signature authority.
    Accountant 4 User responsible for accounting , financial operations and signature authority.
