    Monthly Administrative Report Module Documentation – Overview

    PurposeController responsible for managing monthly administrative reports with validation, OTP approval, printing, and exporting.
    AreaAdmin
    AuthorizationAdminAuthorize
    DependenciesIMonthlyAdministrativeReportService, IMapper

    OTP Approval Workflow

    StepDescription
    Initial AddNotification sent to ActivityMonitor.
    New QuarterNotification sent to Manager with quarter info.
    First Quarter of YearAnnual notification sent to Manager.
    First OTP SignActivityMonitor signs, editing disabled for all except Manager, notification sent to Manager.
    Manager EditManager update removes ActivityMonitor sign and sends update notification.
    Manager ValidationEditing disabled for all users and Print enabled.
    Delete RuleDelete disabled after first OTP signature.

    Index Action

    PurposeMain report listing with filtering and pagination.
    FiltersYear (from database), Month (1–12 localized).
    Pagination50 records per page.
    UIAJAX partial view loading, enum-to-text conversion.

    AddEdit (GET)

    PurposeDisplay create/edit form.
    ParametersOptional report ID.
    Enum SupportMonthlyAdministrativeReportType dropdown.

    AddEdit (POST)

    PurposeSave or update monthly report.
    ValidationModelState and month/year/type uniqueness.
    Business RuleNo duplicate reports per month/year/type.
    RedirectCreate → Index, Edit → AddEdit.

    Delete Action

    PurposeRemove report record.
    MethodHTTP POST.
    FlowService deletion then redirect to Index.

    View-Only Operations

    DetailsRead-only report details with enum text conversion.
    PrintDetailsPrintable report view for official documentation.

    OTP Endpoints

    SendOtpInitiates OTP for trainer or manager approval.
    ValidateOtpValidates OTP and applies digital signature.
    SecurityNoLogging and IgnoreAction attributes.

    CheckDate Endpoint

    PurposeAJAX validation for duplicate month/year/type.
    ReturnsBoolean JSON result.
    UsageClient-side validation.

    Print & Excel Export

    PrintPrinter-friendly report list.
    ExcelDownloadable Excel with localized month and type.
    File NameMonthlyAdministrativeReportList_YYYYMMDD_HHmmss.xlsx
