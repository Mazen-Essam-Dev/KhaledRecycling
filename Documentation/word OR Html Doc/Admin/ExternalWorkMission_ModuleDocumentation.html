    Action Purpose Key Features
    Index Main mission listing Employee search, date filters, AJAX pagination (50/page)
    AddEdit (GET) Display create/edit form Employee dropdown, job title auto-display
    AddEdit (POST) Create or update mission Mission types management, redirect logic
    Delete Delete mission POST-only, service-based deletion
    Details Read-only mission details IgnoreAction, employee context shown
    PrintDetails Printable mission details Professional print layout
    SendOtp Initiate OTP approval NoLogging, JSON response
    ValidateOtp Validate OTP approval JSON result with status and message
    Print Printable mission list No pagination, keeps filters
    createExcelReport_Download Export missions to Excel Localized data, timestamped XLSX
