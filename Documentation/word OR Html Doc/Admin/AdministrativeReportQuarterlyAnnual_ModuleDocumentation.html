    Administrative Report Quarterly & Annual System Documentation

    Controller Overview

    ASP.NET Core Controller for managing quarterly and annual administrative reports with activity tracking and signature verification.

    PropertyValue
    AreaAdmin
    AuthorizationAdminAuthorize
    DependenciesIAdministrativeReportQuarterlyAnnualService, IMapper (AutoMapper)

    Action Methods

    MethodPurposeParametersFeatures
    Index Main dashboard for quarterly/annual reports selectedYear (optional) Year dropdown population, Quarterly data aggregation, Activity and administrative counts calculation, Collaborative report signature checking, AJAX partial view support
    All2Details Combined administrative and activities details view selectedYear, quarter, pagination Delegates to service layer, Signature verification, Returns mapped data
    AdminstrativeDetails Administrative-only reports view selectedYear, quarter, pagination Quarter filtering, Annual summary (quarter=5), Signature verification
    ActivitiesDetails Activities-focused reports with chart data selectedYear, quarter, pagination Pie chart data, Monthly participation, Activity duration, Quarter-based grouping

    Print Methods

    MethodPurpose
    PrintActivitiesDetailsPrintable version of activities report
    PrintAdminstrativeDetailsPrintable administrative reports
    PrintAll2DetailsPrintable combined reports

    All use [IgnoreAction] attribute to exclude routes.

    Signature & OTP System

    FeatureDescription
    SendOtp Generates and sends OTP for specific roles (trainer/manager)
    ValidateOtp Verifies OTP codes for report signing with [NoLogging] attribute
    Signature Integration Signature checking across all detail views, Role-based authorization, Quarterly report type differentiation
