    HomeController – Overview
    Controller Name HomeController
    Framework ASP.NET Core MVC
    Purpose Serves as the central hub for admin area navigation, language management, and system-level utilities including redirects and error-safe operations.
    Primary Role Admin dashboard entry point and system-level helper controller

    Controller Configuration
    Area Admin
    Authorization AdminAuthorize Attribute
    Route Template Admin/[controller]/[action]
    Routing Strategy Fixed route for centralized admin navigation

    Action: Index
    Purpose Main admin entry action
    Behavior Redirects to Statistics controller Index action
    Return Type RedirectToActionResult
    Use Case Acts as the default landing page for the admin area

    Index Action – Attributes
    [NoLogging] Prevents this navigation action from being logged
    [IgnoreAction] Excludes the action from route discovery and menus

    Language Management System
    Action Name ChangeLanguage
    Purpose Switch application language dynamically (Arabic / English)
    HTTP Method GET
    Input Parameter lang (Language code)

    ChangeLanguage – Session & Navigation
    Session Key CurrentCulture
    Session Value Language code (e.g., ar / en)
    Redirect Logic Returns user to the referring page
    Fallback Redirect Redirects to root ("/") if Referer is not available

    ChangeLanguage – Attributes
    [NoLogging] Language changes are excluded from activity logs
    [IgnoreAction] Hidden from menus and route scanners
    [HttpGet] Safe GET request for switching language

    ChangeLanguage – Core Logic
    Session Assignment HttpContext.Session.SetString("CurrentCulture", lang);
    Referer Retrieval var referer = Request.Headers["Referer"].ToString();
    Redirect Execution return Redirect(referer ?? "/");

    Module Summary
    Responsibility Scope Admin navigation, culture switching, system-level redirection
    Security Level Admin-only access
    Logging Strategy Critical system actions excluded from logging
    Design Goal Clean, centralized, and low-risk admin entry controller
