    BudgetItemController - Action Methods

    Controller Actions
    Action Purpose Parameters Notes / Features
    Index Main budget item listing searchTerm, pagination Text & numeric search, combined OR logic, AJAX partial view, paginated list (50 items)
    AddEdit (GET) Display create/edit form id (optional) Auto-generate new ItemNumber on create, maps existing item on edit
    AddEdit (POST) Handle form submission BudgetItemVM model ModelState validation, Anti-forgery token, redirects to Index or edit form
    Delete Remove budget item id Service deletion, TempData feedback on failure, boolean result handling
    Print Printer-friendly list Filters applied Same search as Index, no pagination, [IgnoreAction]
    createExcelReport_Download Generate Excel report Filters applied Bilingual columns, timestamped XLSX file "BudgetItemsList_YYYYMMDD_HHmmss.xlsx"

    BudgetItemService - Methods

    Service Methods
    Method Purpose Parameters Notes / Behavior
    GetAllAsync Retrieve all budget items None Returns IEnumerable<BudgetItem>
    GetByIdAsync Fetch budget item by ID int id Nullable return, repository lookup
    AddAsync Create new budget item BudgetItem entity Unique ItemNumber validation, auto-generation, transaction commit, returns new ID
    UpdateAsync Update existing budget item BudgetItem entity Fetch existing, update values, commit transaction, null-check safety
    DeleteAsync Remove budget item int id Try-catch, boolean result indicating success/failure, commits transaction
    GenerateNewCode Create unique sequential item numbers None Finds max existing code, increments by 1, fallback to 1000 on error

    BudgetItem Entity - Fields

    Database Model Properties
    Property Description
    IdPrimary key of the budget item
    ItemNumberOptional number/identifier for accounting or organization
    ItemTitleName or title of budget item (max 200 chars)

    BudgetItemVM - Fields

    Presentation Layer / UI Properties
    Property Description
    IdSame as entity
    ItemNumberShown in UI but optional, read-only for integrity
    ItemTitleRequired in UI, localized validation
    HasRelatedExpenseOrReceiptNot stored in DB. Indicates if item is referenced elsewhere; may disable edit/delete
