    Dependencies

    SupplierService Operations

    Method Purpose Key Notes
    GetAllAsync() Retrieve all suppliers • Uses AsNoTracking()
    • Dynamically sets HasRelatedData
    • Checks Expenses, Receipts, PurchaseOrders
    GetByIdAsync(int id) Fetch supplier by ID Returns nullable Supplier entity
    AddAsync(Supplier) Create new supplier Returns generated supplier ID
    UpdateAsync(Supplier) Update existing supplier Includes null safety checks
    DeleteAsync(int id) Delete supplier Prevents deletion if entity not found

    Relationship Integrity Logic

    Feature Implementation
    HasRelatedData context.Expenses.Any(e => e.SupplierId == s.Id) || context.Receipts.Any(r => r.SupplierId == s.Id) || context.PurchaseOrders.Any(po => po.SupplierId == s.Id)
