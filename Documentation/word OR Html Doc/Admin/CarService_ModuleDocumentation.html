    CarServiceManager - Methods

    Service Layer
    Method Purpose Parameters Notes / Behavior
    GetAllAsync Retrieve all car services None Includes related Car entity
    GetByIdAsync Retrieve single service by id int id Includes related Car
    AddAsync Add a new service CarServiceEntity entity, IFormFile? file Saves attachment if provided, updates entity, returns tuple (Id, CarId)
    UpdateAsync Update existing service CarServiceEntity entity, IFormFile? file Deletes old attachment if new file uploaded, updates entity values, commits changes
    DeleteAsync Delete service record int id Deletes attached file if exists, deletes entity, commits changes
