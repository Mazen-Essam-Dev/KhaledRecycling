    ActivityController Actions Overview

    ActionPurpose / Features
    IndexDisplay paginated activities, filter by date/keyword, calculate duration and subscription count, supports Ajax partial views
    AddEditCreate/Edit activity, file attachment management (PDF ≤ 5MB), dropdown refill on validation fail, temporary file storage, validation for type/size
    DetailsPartialView display of activity details, file existence check, dynamic duration, lightweight modal
    MembersActivityDisplay members of an activity, pagination, filtering, combined activity/member ViewModel, supports Ajax
    DeleteDelete activity by id, async, admin authorization, redirects to list
    Print & ExportToExcelPrint/export activities, keyword/date filtering, calculate duration/subscription count, bilingual formatting, dynamic columns, improved date formatting
    createExcelReport_DownloadDownload filtered activity data as Excel, DTO conversion, localization, timestamp-based file naming, try-catch error handling
    PrintMembersActivity / createExcelReport_Download_MembersActivityPrint/export subscribed members, includes nationality, age, contact, activity context, bilingual support

    MethodPurpose / Notes
    GetAllAsyncRetrieve all activities asynchronously
    GetByIdAsyncRetrieve activity by id, returns null if not found
    AddAsyncAdd activity, optional file upload, transactional save, returns new Id
    UpdateAsyncUpdate activity, optional file replacement, preserves old file paths, uses UpdateValues pattern
    DeleteAsyncDelete activity, cleanup file attachment, transaction commit
    GetAllMembersOfActivityAsyncGet members subscribed to activity, eager load Nationality, separate member/subscription retrieval
