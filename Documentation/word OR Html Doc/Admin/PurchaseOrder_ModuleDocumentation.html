    Purchase Order Module – Full Documentation

    PurchaseOrderController – Overview

    PurposeManage purchase orders with supplier integration, auto-code generation, and OTP approval workflow.
    AreaAdmin
    AuthorizationAdminAuthorize
    Dependencies IPurchaseOrderService
    IMapper

    OTP Approval Workflow

    OTP RoleManager only
    On CreateNotification sent to Manager
    On UpdateUpdated notification sent to Manager
    First SignatureManager signs first
    After Signature Editing disabled for all users
    Delete button disabled
    Print enabled

    Controller Actions

    Index List purchase orders
    Filters: Supplier, DateFrom, DateTo
    Pagination: 50 items
    AJAX partial view supported
    AddEdit (GET) Create / Edit purchase order
    Auto-generate purchase order code
    Load supplier dropdown
    AddEdit (POST) Validate model state
    Preserve code on validation failure
    Redirect logic based on create/edit
    Delete HTTP POST only
    Deletes order and related items
    Details Read-only view
    Supplier and financial details
    PrintDetails Printable purchase order
    Used for official documentation

    Reporting & Export

    Print Printer-friendly list
    Same filters as Index
    No pagination
    Excel Export Columns: Order Code, Supplier Name, Date
    Bilingual (AR / EN)
    File name format:
    PurchaseOrderList_YYYYMMDD_HHmmss.xlsx

    Service Core Methods

    GetAllAsyncRetrieve all purchase orders with signatures
    GetByIdAsyncGet order with items and signature
    GetAllSuppliersAsyncReturn supplier list (Arabic / English)
    AddAsyncCreate order and calculate totals
    UpdateAsyncUpdate order and replace items
    DeleteAsyncDelete order and items

    Auto Code Generation

    Logic Sequential numeric codes
    Start from 188 if empty
    Collision check before assignment
    Example 188 → 189 → 190
