    Service Methods
    Method Purpose Parameters Notes / Behavior
    GetAllAsync Retrieve all documents None Returns IEnumerable<ArchivingDocument>, async
    GetByIdAsync Fetch document by ID int id Nullable return, repository lookup

    UpdateAsync Update existing document ArchivingDocument entity Handles file replacement if uploaded, preserves path if no file, commits changes
    DeleteAsync Delete document and PDF int id Deletes physical file, removes DB record, commits transaction
