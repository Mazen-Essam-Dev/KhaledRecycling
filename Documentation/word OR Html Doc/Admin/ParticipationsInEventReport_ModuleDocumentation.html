    ParticipationsInEventReportController – Overview

    PurposeManages event participation reports with OTP approval, filtering, printing, and Excel export.
    AreaAdmin
    AuthorizationAdminAuthorize
    DependenciesIParticipationsInEventReportService, IMapper

    Index Action

    PurposeMain listing with filtering and pagination.
    FiltersSearch (ReportTitle), DateFrom, DateTo.
    Pagination50 records per page.
    AJAXReturns partial view for AJAX requests.
    StateFilters preserved via ViewBag and sessionStorage.

    AddEdit (GET)

    PurposeDisplay create/edit participation report form.
    ParameterOptional report ID.
    FlowLoad existing report for edit or new VM for add.

    AddEdit (POST)

    PurposeHandle create/update submission.
    ValidationModelState validation.
    RedirectCreate → Index, Edit → same AddEdit page.

    Delete Action

    PurposeDelete participation report.
    MethodHTTP POST.
    FlowService deletion → Redirect to Index.

    View-Only Operations

    DetailsRead-only report view with activities, images, and signatures.
    PrintDetailsPrinter-friendly single report view.
    PrintPrinter-friendly list of reports.

    OTP Approval Workflow

    SendOtpSends OTP for trainer or manager approval.
    ValidateOtpValidates OTP and applies digital signature.
    SecurityNoLogging + Anti-forgery protection.
    UIBootstrap modal with AJAX verification.

    Excel Export

    PurposeExport filtered participation reports to Excel.
    ColumnsReportTitle, AdministrativeDepartment, Date.
    LocalizationArabic / English support.
    File NameParticipationsInEventList_YYYYMMDD_HHmmss.xlsx
