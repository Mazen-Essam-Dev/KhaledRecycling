    OTP Workflow – General Rules

    Role OrderAccountant → Manager
    TriggerNew salary entry sends notification to Accountant
    ReportsPayroll Report & Discounts and Bonuses Report
    Notes Old print actions deprecated.
    Reports are independent and parallel.
    Editing is not disabled after first sign.
    Updating data does not remove old signatures.

    OTP – Payroll Report

    ReportOpenDetails_payrollReport
    Signing OrderAccountant first → Manager second
    Behavior Accountant signs → Manager receives notification.
    Manager signs → Editing disabled and print enabled.

    OTP – Discounts & Bonuses Report

    ReportOpenDetails_DiscountsAndBonusesReport
    Signing OrderAccountant first → Manager second
    Behavior Accountant signs → Manager notified.
    Manager signs → Editing disabled and print enabled.

    Salary Calculation Logic

    Total SalaryBasic Salary + Allowances
    Absence Deduction(Total Salary ÷ 30) × Absent Days
    Annual Leave Deduction(Allowances ÷ 30) × 0.5 × Annual Leave Days
    Total DeductionsAbsence + Annual Leave + Additional Deductions
    Net SalaryTotal Salary - Total Deductions + Bonuses
