    AttachmentVM Properties

    Property Type Description
    Id int The unique identifier of the attachment.
    Name string? The display name of the attachment.
    Path string? The file path of the attachment (max length 300).
    File IFormFile? The uploaded file object. Null if no file is uploaded.

    EmployeeAttachmentsVM Properties

    Property Type Description
    EmployeeId int The unique identifier of the employee.
    Attachments List<AttachmentVM>? A list of attachment view models associated with the employee. Can be null.

    Employee Model Properties

    Property Type Description Constraints / Notes
    Id int Unique identifier for the employee. Primary key 🔑
    Code string Unique employee code. Required
    FullName string? Full name of the employee. MaxLength(100)
    PhoneNumber string? Contact phone number. MaxLength(20)
    NationalityId int? Foreign key referencing Nationality. Optional
    DepartmentId int? Foreign key referencing Department. Optional
    Email string? Email address. MaxLength(100)
    JobTitle string? Job or role title. MaxLength(100)
    Address string? Home or work address. MaxLength(200)
    PassportNumber string? Passport number. MaxLength(50)
    PassportExpiryDate DateOnly? Passport expiration date. Optional 📅
    NationalIdNumber string? National ID number. MaxLength(50)
    NationalIdExpiryDate DateOnly? National ID expiration date. Optional 📅
    BankAccountNumber string? Bank account number. MaxLength(50)
    BankName string? Bank name. MaxLength(100)
    PhotoPath string? Path to employee's profile photo. MaxLength(200)
    Salary double? Salary amount. Nullable 💰
    Notes string? Additional notes. No length constraint ✍️
    Type int Type identifier (permanent/trainer/contractor). Required; role-based logic

    Employee Model Relationships

    Navigation Property Type Description
    Courses ICollection<Course> Courses conducted or attended by the employee.
    Department Department? Department to which the employee belongs.
    Nationality Nationality? Nationality of the employee.

    EmployeeAttachment Properties

    Property Type Description
    Id int Primary key for the attachment.
    Name string? Name of the attachment. Max length 100.
    Path string? File path of the attachment. Max length 300.
    File IFormFile? Used for uploading the file via forms. Not mapped to DB.
    EmployeeId int Foreign key referencing the employee.

    AttachmentDTO Properties

    Property Type Description
    Id int Unique identifier of the attachment.
    Name string? Name or title of the attachment.
    Path string? Path to the saved file (max 300 chars).
    File IFormFile? The actual uploaded file.

    EmployeeAttachmentsDTO Properties

    Property Type Description
    EmployeeId int The unique identifier of the employee.
    Attachments List<AttachmentDTO>? A list of attachments for the employee. Can be null.

    EmployeesController Actions

    Action Signature Description
    Index public async Task<IActionResult> Index(string? searchTerm, DateOnly? dateFrom, DateOnly? dateTo, int page = 1, int pageSize = 50) Displays paginated employee list with optional filters. Returns View or PartialView with EmployeeVM.
    AddEdit (GET) public async Task<IActionResult> AddEdit(int? id) Displays form to add or edit employee. Populates nationality dropdowns.
    AddEdit (POST) [HttpPost] public async Task<IActionResult> AddEdit(EmployeeVM model) Handles submission for creating/updating employee. Validates file uploads.
    Details [IgnoreAction] public async Task<IActionResult> Details(int id) Displays full details of a single employee. Preserves previous URL.
    PrintDetails [IgnoreAction] public async Task<IActionResult> PrintDetails(int id) Returns a printable view of employee details.
    GetEmployeeAttachments public async Task<IActionResult> GetEmployeeAttachments(int id) Returns a partial view of employee attachments.
    UploadEmployeeFiles [HttpPost] public async Task<IActionResult> UploadEmployeeFiles(EmployeeAttachmentsVM model) Handles uploading of employee attachments.
    Delete [HttpPost] public async Task<IActionResult> Delete(int id) Deletes an employee by ID. Redirects back to Index.
    Print [IgnoreAction] public async Task<IActionResult> Print(string? searchTerm, DateOnly? dateFrom, DateOnly? dateTo, int page = 1, int pageSize = 50) Returns printable employee list filtered by search term and dates.
    createExcelReport_Download [IgnoreAction] public async Task<IActionResult> createExcelReport_Download(string? searchTerm, DateOnly? dateFrom, DateOnly? dateTo, int page = 1, int pageSize = 50) Generates and downloads Excel report of employees filtered by search term/date range.

    EmployeeService Methods

    Method Signature Description
    HasRelatedObjectsInDb public async Task<bool> HasRelatedObjectsInDb(int empId) Checks if employee has related records in other tables (ExternalWorkMissions, SalaryManagements, EmployeeAttachments).
    GetAllAsync public async Task<IEnumerable<Employee>> GetAllAsync() Returns all employees including their Nationality.
    GetByIdAsync public async Task<Employee?> GetByIdAsync(int id) Returns a single employee by ID.
    AddAsync public async Task<int> AddAsync(Employee entity) Adds a new employee. Saves employee photo if provided.
    UpdateAsync public async Task UpdateAsync(Employee entity) Updates an existing employee. Handles image replacement if new photo uploaded.
    DeleteAsync public async Task DeleteAsync(int id) Deletes an employee by ID and removes associated photo file from disk.
    UploadAttachmentsAsync public async Task UploadAttachmentsAsync(EmployeeAttachmentsDTO model) Handles uploading employee attachments. Deletes old files removed from list and saves new files.
    GetAttachmentsAsync public async Task<IEnumerable<EmployeeAttachment>> GetAttachmentsAsync(int empId) Retrieves all attachments for a specific employee.
