## المستخدمون

### المستخدمون الرئيسيون

| النوع | الدور |
|-------|-------|
| **العميل (فرد/شركة)** | يبيع النفايات للنظام، يجمع نقاط، يحصل على خصومات |
| **المصنع** | يشتري المواد المعالجة، يمنح نقاط إضافية للنظام |
| **المشرف** | يدير المخازن والمعارض والحركات المالية |

## نظام النقاط

### نظام النقاط الأساسي

#### 1. التحويل الأساسي
- كل **1000 دولار** عمليات = **100 نقطة**

#### 2. صرف النقاط (من وجهة نظر العميل)
- **500 نقطة** = خصم **1%**
- العميل (فرد أو شركة نوع 1 أو 2) يستخدم هذا النظام

#### 3. صرف النقاط (من وجهة نظر المصنع)
- **2000 نقطة** = خصم **1%**
- المصنع (نوع 3) يستخدم هذا النظام

#### 4. الحد الأقصى (Max Ratio)

| العملية | الحد الأقصى |
|---------|-------------|
| **البيع** (Sell) | خصم **30%** |
| **الشراء** (Buy) | إضافة **20%** للنظام |

### نظام النقاط المتقدم

#### نظام التدرج (Tiered System)

| النقاط المتراكمة | المستوى | الخصم الأقصى |
|------------------|---------|--------------|
| 0 - 5,000 | Bronze | 10% |
| 5,001 - 15,000 | Silver | 15% |
| 15,001 - 30,000 | Gold | 20% |
| 30,000+ | Platinum | 30% |

## سيناريوهات المخازن

### هيكل الغرفة (Room Structure)

```csharp
// عند الإنشاء:
MaxUnits = 100      // السعة القصوى
FilledUnits = 0     // الممتلئ حالياً
ReservedUnits = 0   // المحجوز
Free = Max - (Filled + Reserved) = 100
```

### حالات الغرف

| الحالة | Filled | Reserved | Free | معنى |
|--------|--------|----------|------|------|
| Empty | 0 | 0 | 100% | فارغة |
| Partially Filled | 30 | 0 | 70% | ممتلئة جزئياً |
| Partially Reserved | 20 | 20 | 60% | محجوزة جزئياً |
| Full/Reserved | 80 | 20 | 0% | ممتلئة بالكامل |

### العمليات على الغرف

```
┌─────────────────────────────────────────────────────────────┐
│           العمليات على المخزن/المعرض (Room)                  │
├─────────────────────────────────────────────────────────────┤
│  المتغيرات:                                                │
│  • MaxUnits     = السعة القصوى                              │
│  • FilledUnits  = الممتلئ حالياً                            │
│  • ReservedUnits = المحجوز                                  │
│  • Free         = Max - (Filled + Reserved)                │
├─────────────────────────────────────────────────────────────┤
│  العمليات:                                                  │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐          │
│  │  الإيداع  │  │   الحجز    │  │   السحب    │          │
│  │ (Deposit) │  │ (Reserve)  │  │ (Withdraw) │          │
│  ├─────────────┤  ├─────────────┤  ├─────────────┤          │
│  │ Filled += n│  │Reserved += n│  │ Filled -= n │          │
│  │ Free -= n   │  │ Free -= n   │  │ Free += n   │          │
│  └─────────────┘  └─────────────┘  └─────────────┘          │
├─────────────────────────────────────────────────────────────┤
│  تعديل الحجم (Validation):                                  │
│  if (NewMax < Filled + Reserved)                           │
│      ERROR: "لا يمكن أن تكون السعة أقل من (الممتلئ + المحجوز)"│
└─────────────────────────────────────────────────────────────┘
```

## سيناريوهات الطلبات

### دورة حياة الطلب

```
┌─────────────────────────────────────────────────────────────────┐
│                    دورة حياة الطلب (Order Lifecycle)              │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌────────┐ │
│   │  Pending │────→│ Approved │────→│  Done    │────→│ Supply │ │
│   │ (معلق)  │     │ (معتمد)  │     │ (منتهي)  │     │(تسليم) │ │
│   └──────────┘     └──────────┘     └──────────┘     └────────┘ │
│        │                │                │                │     │
│        ↓                ↓                ↓                ↓     │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌────────┐ │
│   │ Cancelled│     │ Rejected │     │ Archived │     │Completed│ │
│   │ (ملغي)  │     │ (مرفوض)  │     │ (مؤرشف)  │     │(مكتمل) │ │
│   └──────────┘     └──────────┘     └──────────┘     └────────┘ │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### أنواع الطلبات

| النوع | الوصف | الاتجاه |
|-------|-------|---------|
| OrderBuyFromClient | شراء نفايات من عميل | النظام ← العميل |
| OrderSellToClient | بيع منتج معالج لعميل | النظام → العميل |
| OrderBuyFromFactory | شراء مواد من مصنع | النظام ← المصنع |
| OrderSellToFactory | بيع مواد معالجة لمصنع | النظام → المصنع |

## الخلاصة

### ملخص شامل للنظام

**النظام يتكون من:**

| المجال | الوظيفة |
|--------|---------|
| **إدارة المستخدمين** | العملاء (1,2) + المصانع (3) + المشرفون |
| **إدارة المخازن** | مخازن النفايات + غرف المخازن |
| **إدارة المعارض** | معارض المنتجات + غرف المعارض |
| **إدارة الطلبات** | شراء/بيع من/إلى العملاء والمصانع |
| **النظام المالي** | نقاط + خصومات + تقارير مالية |
| **التقارير** | طباعة + Excel + إحصائيات |
